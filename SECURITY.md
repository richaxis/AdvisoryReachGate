# Security

This is an experimental test-network release (Studio Next) and has not been independently audited. Do not use it to gate production decisions.

- Evidence is untrusted data. The contract never executes or imports fetched content.
- Never commit a wallet key, password or token. Use an encrypted keystore.
- Static advisory-versus-pin checks are not proof that code is or is not exploitable.
- Shared model mistakes remain possible on the prose-advisory path. The contract narrows this with quote grounding and exact-match consensus but cannot remove it.

To report a problem, open a private security advisory on the GitHub repository, or an issue if that is unavailable.
